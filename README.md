# illill

일일체크 화면에서 날짜 이동, 자동 체크, 체크 취소, 그리고 여러 날짜에 대한 기간 일괄 처리를 간편하게 도와주는 크로미움 기반 브라우저 확장 프로그램입니다.

- **현재 버전**: `3.1.1`
- **지원 브라우저**: Chrome, Whale, Edge

---

## 설치 방법

이 확장 프로그램은 스토어를 거치지 않고 ZIP 압축을 푼 뒤 브라우저의 **개발자 모드**에서 직접 불러와 설치합니다.

### 1단계: 압축 풀기

1. 먼저 `.zip` 파일을 다운로드해주세요.
2. 안전한 디렉토리에서 파일의 압축을 풀고 저장해주세요.
3. 압축을 푼 디렉토리를 열었을 때 `manifest.json` 파일이 **바로 보이는지** 확인하세요.
   - 만약 디렉토리 안에 같은 이름의 디렉토리가 하나 더 들어 있다면, `manifest.json`이 들어있는 디렉토리의 상위 디렉토리를 선택하세요.

> [진짜루중요함!]
> 확장 프로그램을 불러온 뒤에는 저장한 디렉토리를 **삭제하거나 다른 위치로 옮기지 마세요.** 디렉토리가 사라지면 확장 프로그램도 함께 멈추게 돼요.

---

### 2단계: 브라우저에서 확장 프로그램 불러오기

사용 중인 브라우저에 맞춰 순서대로 진행해주세요.

#### Chrome
1. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
2. 화면 우측 상단의 **개발자 모드** 스위치를 켭니다.
3. 좌측 상단에 나타난 **압축해제된 확장 프로그램을 로드합니다** 버튼을 클릭합니다.
4. 1단계에서 압축을 풀어 둔 디렉토리를 선택한 뒤 선택을 누릅니다.

#### Whale
1. 웨일 주소창에 `whale://extensions` 를 입력하고 Enter를 누릅니다.
2. 화면 우측 상단의 **개발자 모드** 스위치를 켭니다.
3. 좌측 상단의 **압축해제된 확장 프로그램을 로드합니다** 버튼을 클릭합니다.
4. 1단계에서 압축을 풀어 둔 디렉토리를 선택한 뒤 선택을 누릅니다.

#### Edge
1. 엣지 주소창에 `edge://extensions` 를 입력하고 Enter를 누릅니다.
2. 화면 좌측 메뉴(또는 좌측 하단)의 **개발자 모드** 스위치를 켭니다.
3. 상단에 나타난 **압축 풀린 파일 로드** 버튼을 클릭합니다.
4. 1단계에서 압축을 풀어 둔 디렉토리를 선택한 뒤 선택을 누릅니다.
---

### 3단계: 툴바에 고정하기

1. 브라우저 우측 상단의 **퍼즐 조각 아이콘** 을 클릭합니다.
2. 목록에서 **illill** 옆의 **고정 아이콘**을 누릅니다.
3. 브라우저 상단 바에 아이콘이 고정되면 필요할 때마다 바로 클릭해 열 수 있습니다.

---

## 기능별 사용법

### 1. 연결 상태 확인
1. 통합정보시스템에 로그인한 뒤, 평소처럼 **일일체크** 메뉴 탭을 엽니다.
2. 브라우저 상단에 고정한 **illill** 아이콘을 클릭합니다.
3. 팝업 상단 배지가 초록색 **`연결됨`** 으로 표시되면 바로 사용할 수 있습니다.
   - 만약 주황색 **`미감지`** 배지와 안내 배너가 뜬다면, 현재 탭이 일일체크 화면이 맞는지 확인한 뒤 배너의 **다시 확인** 버튼이나 상단의 **새로고침** 아이콘을 눌러주세요.
4. 연결이 완료되면 달력에서 이미 체크된 날짜 아래에 **초록색 점**이 표시되며, 달력 상단에 **`이달 N일 체크됨`** 요약이 함께 나타납니다.

---

### 2. 날짜 선택 (단일 날짜 처리)
상단 탭이 **날짜 선택**에 맞춰져 있을 때 한 날짜씩 세밀하게 처리할 수 있습니다.

- **날짜 고르기**: 달력에서 원하는 날짜를 클릭하거나, 날짜 양옆의 **`<`(하루 전)** / **`>`(하루 뒤)** 버튼, 달력 상단의 **`오늘`** 버튼을 눌러 선택합니다.
- **상태 확인**: 선택한 날짜 오른쪽 배지에서 **`체크 완료`** 또는 **`미체크`** 상태를 바로 확인할 수 있습니다.
- **일일체크**: 선택한 날짜로 체크를 저장합니다.
- **날짜 이동**: 체크나 취소 없이 포털 화면의 선택 날짜만 해당 날짜로 이동시킵니다.
- **체크 취소**: 선택한 날짜에 저장된 체크 기록을 삭제합니다. (해당 날짜에 기록이 없으면 안내 로그가 남습니다.)

---

### 3. 기간 지정 (일괄 처리)
상단 탭을 **기간 지정**으로 전환하면 여러 날짜를 한 번에 처리할 수 있습니다.

- **직접 기간 선택**: 달력에서 **시작일**을 먼저 클릭한 뒤 **종료일**을 한 번 더 클릭합니다. (시작일보다 앞선 날짜를 두 번째로 클릭해도 자동으로 순서가 맞춰집니다.)
- **빠른 기간 선택**: **`최근 3일`**, **`최근 7일`**, **`이번 주`**, **`이번 달`** 버튼으로 자주 쓰는 기간을 한 번에 지정할 수 있습니다.
- **기간 안내 확인**: 선택한 기간의 총 일수와 **`미체크 N일 포함`** 안내를 미리 확인할 수 있습니다.
- **일괄 실행 및 중지**
  - **`N일 일괄 체크`**: 선택한 기간의 날짜를 하루씩 순서대로 체크합니다.
  - **`일괄 취소`**: 선택한 기간의 체크 기록을 하루씩 삭제하며, 기록이 없는 날짜는 자동으로 건너뜁니다.
  - 작업 중에는 진행률 바가 표시되며, 멈추고 싶을 때 **`작업 중지`** 버튼을 누르면 현재 날짜 처리 후 안전하게 중단됩니다.

---

### 4. 설정
상단 우측의 **톱니바퀴(설정)** 아이콘을 누르면 아래 항목을 확인하고 변경할 수 있습니다.

- **요청 간 대기 시간**: 일일체크/취소 요청 후 다음 작업으로 넘어가기 전 기다리는 시간입니다.
  - **`0.9초` (빠름)** / **`1.2초` (권장)** / **`1.6초` (안정)** / **`2.2초` (느림)** 중 선택할 수 있으며, 선택한 값은 브라우저 로컬 저장소에 자동 저장됩니다.
- **포털 연동 정보**: 현재 포털 화면에 선택된 날짜(**현재 포털 날짜**)와 불러온 전체 기록 건수(**전체 저장 기록**)를 확인합니다.

---

### 5. 활동 기록 (하단 로그 바)
- 팝업 하단 바에서 가장 최근에 실행한 작업 결과를 한 줄로 확인할 수 있습니다.
- 하단 바를 클릭해 펼치면 시간순 상세 작업 내역(이동, 완료, 취소, 건너뜀, 오류 등)을 확인할 수 있으며, **비우기** 버튼으로 목록을 초기화할 수 있습니다.

---

## 주의사항

- **실제 실행 시점 기록 안내**: 일일체크를 실행하면 서버에는 **선택한 날짜**와 함께 **실제 실행한 시점(날짜·시간)** 이 기록됩니다. 반드시 소속 생활관 규정에 맞게 사용해 주세요.
- **폴더 유지 필수**: 개발자 모드로 불러온 압축 해제 폴더를 삭제하거나 이동하면 확장 프로그램이 동작하지 않습니다.
- **브라우저 재실행 시 알림**: 네이버 웨일 등 일부 브라우저에서는 재실행 시 개발자 모드 확장 프로그램 사용 여부를 확인하는 창이 뜰 수 있습니다. **사용**을 누르면 계속 이용할 수 있습니다.
- **네트워크 지연 시 대기 시간 조절**: 학교 포털 응답이 느리거나 일괄 처리 도중 일부 날짜가 누락된다면, 설정에서 요청 간 대기 시간을 **`1.6초(안정)`** 또는 **`2.2초(느림)`** 로 높여 다시 실행해 보세요.
- **권한 및 개인정보 안내**: 이 확장 프로그램은 `activeTab`, `scripting`, `storage` 권한만 사용하며, 사용자가 아이콘을 클릭해 연 현재 탭에서만 동작합니다. 외부 서버로 데이터를 전송하지 않으며 대기 시간 설정값만 브라우저 내부에 저장합니다.

## 배포용 ZIP 만들기

Git 저장소 메타데이터(`.git`)와 OS 임시 파일, 패키징 스크립트 등을 제외하고 순수 확장 프로그램 파일만 깔끔하게 배포용 ZIP으로 묶는 방법입니다.

### 방법 1: PowerShell 스크립트 사용 (Windows)

프로젝트 루트 폴더에서 아래 명령을 실행하면 `manifest.json`의 버전을 읽어 `illill-v<버전>.zip` 파일을 생성합니다.

```powershell
.\package.ps1
```

만약 실행 정책(ExecutionPolicy) 때문에 스크립트 실행이 차단된다면 아래 명령으로 실행하세요.

```powershell
powershell -ExecutionPolicy Bypass -File .\package.ps1
```

다른 이름이나 경로로 저장하고 싶다면 `-OutputPath` 옵션을 지정할 수 있습니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\package.ps1 -OutputPath .\release\illill.zip
```

### 방법 2: `git archive` 사용 (Windows / macOS / Linux 공용)

Git이 설치되어 있다면 아래 명령으로도 `.git` 및 `.gitattributes`에 지정된 배포 제외 파일 없이 커밋된 파일만 ZIP으로 묶을 수 있습니다.

```bash
git archive --format=zip --output=illill.zip HEAD
```
